# shadowbox

Turn a phone video of a person fighting into a fighter for the simulated G1 arena: video → pose → retarget to the arena's standard Unitree G1 → fighter file.

Early stage; see [PLAN.md](PLAN.md). Code is Apache-2.0 ([LICENSE](LICENSE)). Some optional stages use third-party body models with their own non-commercial licenses; they are not included. See [THIRD_PARTY.md](THIRD_PARTY.md).
